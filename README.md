# Tamagotchi 電子雞 🐣

經典 Tamagotchi P1 的網頁復刻版，像素風格，忠實還原原版機制。

## 遊玩方式

直接開啟 `index.html` 或訪問：  
**https://warrenlin.github.io/Tamagotchi/**

### 操控（3 鍵經典介面）

| 按鈕 | 鍵盤 | 功能 |
|------|------|------|
| A | A / ← | 選擇下一個圖標 |
| B | S / Enter | 確認 / 執行 |
| C | D / Esc | 取消 / 返回 |

### 8 個功能圖標

| 圖標 | 功能 | 說明 |
|------|------|------|
| 🍴 餵食 | 正餐/零食 | 正餐：飢餓+1♥ 體重+1g / 零食：開心+1♥ 體重+2g |
| 💡 燈光 | 開/關燈 | 寵物睡著時需在 15 分鐘內關燈 |
| ⚾ 遊戲 | 猜方向 | 5 回合，猜對≥3 開心+1♥，全對+2♥，體重-1g |
| 💉 治療 | 吃藥 | 生病時使用，可能需要 1-2 劑 |
| 🧹 清潔 | 清便便 | 清除螢幕上的便便 |
| 📢 管教 | 紀律 | 寵物裝哭時使用，紀律+25% |
| 📊 狀態 | 查看數值 | 年齡/體重/紀律/飢餓/開心/失誤 |
| ⚠️ 注意 | 查看需求 | 看寵物現在需要什麼 |

### 進化系統

```
Babytchi (65分鐘)
  └→ Marutchi
       ├─ 好照顧 → Tamatchi
       │    ├─ 100%紀律 → Mametchi ⭐
       │    ├─  75%紀律 → Ginjirotchi
       │    └─  低紀律  → Maskutchi
       └─ 差照顧 → Kuchitamatchi
            ├─ 高紀律 → Kuchipatchi
            ├─ 中等   → Nyorotchi
            └─ 低紀律 → Tarakotchi
```

### 照顧失誤

以下情況 **15 分鐘未處理** = 1 次照顧失誤：
- 飢餓降到 0♥
- 開心降到 0♥
- 寵物睡著未關燈
- 生病未治療

失誤影響進化路線與壽命，累積 5 次成體會死亡。

### 便便系統

- 寶寶每 15 分鐘、其他每 3 小時產生 1 坨
- 最多堆 4 坨，滿了會生病
- 用清潔圖標（🧹）清除

### 睡眠

- 依角色不同，在真實時間的特定時刻自動入睡/起床
- 每次起床年齡 +1 天
